1\. Repository: A repository is a storage location where project files, source code, and documents are kept and managed. It helps developers organize their work and track changes made to a project.

2\. Commit: A commit is a saved record of changes made to files in a repository. It helps developers keep track of their progress and understand what changes were made.

3\. Branch: A branch is a separate version of a project that allows developers to work on new features or make changes without affecting the main project.

4\. Merge: Merge is the process of combining changes from one branch into another, usually bringing completed work into the main branch.

5\. Version Control: Version control is a system used to track and manage changes made to project files over time. It allows developers to review previous changes, restore earlier versions, and collaborate with others.
